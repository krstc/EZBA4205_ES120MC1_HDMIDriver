# HDMI contrast-lift DU5 candidate

日期：2026-09-22

## 修改原因

上一版使用平方近似把中间调压得过低，鼠标残影有所改善，但实际图片整体发黑、细节难以辨认。本版只放松灰度曲线，不修改已验证的 HDMI、EDID、面板时序、DDR 地址或 DU5 状态机。

## 灰度路径

- 输入仍为 8-bit ADV7611 灰度。
- 16..235 先展开到 0..255。
- 仍使用 16x16 蓝噪声二值抖动，原生 GC16 仍关闭。
- 将上一版 `x^2` 改为低成本的移位加法提亮：展开值低于 128 时增加 `1/8`，高于等于 128 时增加 `1/16`，黑白端点保持精确不变。
- 目标是提高中间调白点密度，恢复图片细节，同时不重新引入明显的整屏灰雾。

## 预期密度

输入 16、64、128、192、235、255 的 16x16 白像素数量为 0、61、138、216、256、256。专用仿真应以这些数值验证曲线，其他 HDMI、EDID、I2C、DDR/DU5 回归保持通过。

本版本尚未烧写 NAND，需实测确认照片中的黑化程度是否改善。
