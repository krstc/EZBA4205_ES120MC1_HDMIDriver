# HDMI gamma-aware DU5 candidate

日期：2026-09-21

## 目的

针对实拍画面整体发灰、黑位不够深的问题，建立一个只改变灰度映射的候选版本。该版本不修改已经验证过的 2560x1600、25 Hz HDMI 时序、ADV7611 初始化、DDR 地址布局或 DU5 面板波形。

## 当前显示路径

- HDMI 输入：ADV7611 8-bit 灰度输出。
- 分辨率：2560x1600。
- EDID/像素时钟：2560x1600，2720x1646 总时序，111.93 MHz，约 25 Hz。
- 灰度输出：不是面板原生 16 灰阶；输入经过 16x16 蓝噪声阈值后输出黑白二值像素。
- 面板推进：继续使用已验证的 DU5 每像素状态机，原生 GC16 保持关闭。

## 本次修改

ADV7611 常用视频范围 16..235 先展开到 0..255，然后在蓝噪声二值化前使用可综合的平方近似：

```text
mapped = expanded * expanded / 256
```

黑白端点保持精确不变。相对于直接在线性代码值上抖动，这会减少中间调的白像素密度，压低“整屏灰雾”观感，同时保留空间抖动细节。顶层显式设置 `GAMMA_AWARE_DITHER(1)`，避免依赖模块默认值。

## 离线验证

输入 16、64、128、192、235、255 的 16x16 白像素数量分别为 0、11、66、162、256、256；专用仿真通过。其它 HDMI、EDID、I2C、DDR/ELF、DU5 波形回归也通过后才允许打包。

## 物理验证边界

本候选只隔离“灰度曲线”这一变量，尚未在面板上实测。因此它可以验证灰雾是否主要来自灰度密度映射，但不能在离线阶段保证相机拍摄下的对比度已经达到目标。当前候选不应覆盖上一版基线，也未自动烧写 NAND。
